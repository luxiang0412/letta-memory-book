附录 B 术语表 ​

术语含义章节
agent一个有身份（id）、有记忆的长期存在的智能体；对话是它和外界的一次次交互1
harness包在模型外面的程序：拼上下文、执行工具、存储与整理记忆。letta-code 就是一个 harness0
回合（turn）用户发一条消息，到 agent 给出不带工具调用的回复为止Lab 1
步（step）回合中的一次模型调用。反思的 step-count 触发器数的是 assistant 步14
core memory（核心记忆）常驻系统提示的记忆；v2 中即根目录下的 Markdown 文件1、5
memory block（记忆块）MemGPT/Letta 服务器中的核心记忆单元：label、value、description、limit、read_only4
MemFS记忆文件系统：一个 git 仓库，里面是 Markdown 记忆文件、技能与其他文件2
v1 / v2 布局v1：core 在 system/；v2：core 在根目录，根目录有 MEMORY.md2、5
MEMORY.md无 frontmatter 的索引文件；根索引进入系统提示，子目录索引使该目录成为记忆5
deferred memory（延迟/按需记忆）带索引的子目录里的文件；系统提示中只有目录条目5、8
投影（projection）记忆在文件系统上的表示；isProjectedMemoryPath 判断文件是否属于记忆5
skill（技能）skills/<name>/SKILL.md，程序性记忆，按需加载5
recall memory全部历史消息；只追加，可检索，不可修改1、13
frontmatter文件开头 --- 包围的元数据；v2 要求恰好 name 和 description7
pre-commit hookgit 提交前运行的脚本；记忆仓库用它校验格式和预算7
.memfs.config.json预算与约束配置；本身受保护，修改需要人类批准7
审计（audit）用临时索引校验已提交的 HEAD，防 hook 被绕过7
编译（compile）把已提交的记忆渲染成文本并替换系统提示中的 {CORE_MEMORY}8
{CORE_MEMORY}系统提示里记忆的插入点8
memfsRevision编译时记忆仓库 HEAD 的提交号9
rawSystemHash原始系统提示（未注入记忆）的 sha2569
<memory_update>对话中途记忆变化时追加给模型的新记忆全文；系统提示保持不变3、9
prompt caching（提示缓存）服务商按请求前缀缓存；系统提示一变，缓存全部失效9
<system-reminder>harness 发给模型的自动通知，以 user 角色消息承载9
agent-info每个对话首条消息附带的提醒：agent id、记忆目录等9
地板（floor）系统提示 + 工具定义的 token 数，每次请求都要付11
compaction（压缩）用一条摘要替换上下文开头的一段消息12
sliding window（滑动窗口）只摘要最前面一部分、保留最近消息的压缩模式12
in_context_message_ids当前在上下文窗口里的消息 id 列表12
summary_message压缩摘要消息的类型；存储上是 user 角色12、13
BM25经典的文本相关性排序公式（k1、b 两个参数）13
检索回声（search echo）历史中的检索调用、检索结果、以及正在问的问题本身；需要降权13
reflection / sleeptime / dream对话之间在后台回顾经历、整理记忆的子 agent14、15
compaction-event / step-count反思的两种自动触发器14
水位线（watermark）reflected_through_message_id：反思到了哪条消息14
payload交给反思子 agent 的 transcript 切片文件（$TRANSCRIPT_PATH）15
worktree同一 git 仓库的另一个检出；反思和 worker 在其中工作16
merged / no_changes / parent_dirty / merge_conflict / dirty_uncommitted / failed反思收尾的六种状态；只有前两种消费 transcript16
memory operation lease（记忆操作锁）串行化 harness 自己的记忆写者的文件锁；持有者死亡才回收17
memory worker主 agent 委派的后台记忆更新子 agent17
conflict repair同步冲突或校验失败后启动的修复子 agent17
remoteMemfs / localMemfs后端能力：记忆仓库在服务器上 / 在本机2、18
cross-agent guard进程内文件工具的跨 agent 路径检查（字面 + realpath）19
bwrap（bubblewrap）Linux 上用挂载命名空间实现的沙箱19
SeatbeltmacOS 的沙箱机制（sandbox-exec）19
Memory Palace记忆的只读可视化页面（/palace）20
/doctor用观察到的行为作证据、诊断并修复上下文的流程20
